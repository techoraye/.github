# Techoraye

Developer in Canada. I build **Raye Linux**, **RivenBot**, and the homelab they both run on.

**Raye Linux** — a free Linux desktop for everyday PCs, based on Ubuntu and KDE Plasma, with the taskbar,
Start menu and Settings where Windows users expect them. I wrote the installer, the Store, background updates,
the Settings app, the file manager and a kernel with its own crash screen.
1.0 Beta "Sundog" is out: [rayelinux.com](https://rayelinux.com) · [source](https://github.com/Raye-Linux)

**RivenBot** — a free Discord bot for moderation, raid protection, support tickets, welcome cards and music,
set up from a web dashboard. Node.js bot, Rust services behind the website. [rivenbot.ca](https://www.rivenbot.ca)

**Homelab** — one AMD EPYC server running Proxmox with about thirty virtual machines: OPNsense and WireGuard,
10 Gb switching, a bastion for every SSH session, network-wide DNS filtering, my own mail server and nightly backups.

Also: [Proxmox-CLI](https://github.com/techoraye/Proxmox-CLI) · [BtrfsGuard](https://github.com/techoraye/BtrfsGuard) ·
[metetch](https://github.com/techoraye/metetch) · Gentoo overlays for [Discord](https://github.com/techoraye/discord-bin-overlay)
and [Cursor](https://github.com/techoraye/cursor-bin-overlay) · Android device trees for a Motorola phone.

Manager of the Jxsph community, co-owner of Tech House on Discord.

Daily tools: Linux (Debian and Ubuntu packaging, kernels, Gentoo), Proxmox, OPNsense, Rust, TypeScript and React,
Node.js, Python, PostgreSQL.
